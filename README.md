# Salden’s — заказы

Мобильное веб-приложение для записи заказов по меню Salden’s Taphouse на Мясницкой.

## Возможности

- каталог блюд с категориями, поиском и ценами;
- корзина с автоматическим расчётом суммы;
- сохранение номера стола, имени гостя и комментария;
- рабочая доска со статусами «Новый → Готовится → Готов → Подан»;
- хранение заказов только в браузере пользователя;
- адаптивный интерфейс и установка на главный экран телефона.

Приложение не требует сервера и предназначено для публикации через GitHub Pages.
