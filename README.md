# Хроники Искателя

Первая версия записной книжки для игроков настольных ролевых игр.

## Что уже работает

- несколько отдельных игр/кампаний;
- общая карточка кампании: название, описание, отряд, текущая цель;
- богатый текстовый редактор с заголовками, жирным, курсивом, подчёркиванием, буллитами, нумерацией, цитатами и ссылками;
- отдельные игровые дни/сессии;
- собственная обложка для каждого игрового дня через загрузку файла или drag-and-drop;
- автоматическое уменьшение больших изображений перед сохранением;
- текстовые данные сохраняются в `localStorage`, изображения — в `IndexedDB`;
- экспорт и импорт резервной копии в JSON, включая загруженные обложки;
- адаптивный интерфейс для desktop и mobile;
- PWA/service worker для базовой офлайн-работы.

## Запуск

Можно открыть `index.html` напрямую, но для стабильной работы service worker рекомендуется локальный сервер:

```bash
python -m http.server 8000
```

Затем открыть `http://localhost:8000`.

## Публикация

Проект состоит только из статических файлов и подходит для GitHub Pages.

## Хранение данных

Сервер и аккаунт пока не используются. Данные находятся только в браузере на текущем устройстве. Для переноса между устройствами используйте кнопки «Экспорт» и «Импорт`.
