# Хроники Искателя

Локальный D&D-журнал с двумя основными разделами: **Партии** и **Персонаж**.

## Архитектура

- `src/` — исходный код на TypeScript.
- `dist/` — браузерная ES2022-сборка, публикуемая через GitHub Pages.
- `styles.css` — единая дизайн-система приложения.
- IndexedDB — основной источник локальных данных.
- Service Worker — офлайн-режим и PWA-кеш.
- Supabase — опциональная облачная синхронизация.

Интерфейс собран заново в стилистике премиального fantasy-журнала: пергамент, тёмный кожаный переплёт, бронзовые рамки, бордовые CTA и книжная типографика.

## Разработка

```bash
npm install
npm run typecheck
npm run build
npm run check:dist
```

Собранные файлы `dist/` коммитятся вместе с TypeScript-исходниками, чтобы GitHub Pages мог работать как статический PWA без серверной сборки.
